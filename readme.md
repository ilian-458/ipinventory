# IPINVENTORY

## 🛠️ Prérequis

* **Python 3.10 ou supérieur**
* **pip** (installé avec Python)
* **Git**

## 🚀 Installation du projet

### 1️⃣ Cloner le projet (si via Git) 
(Vous pouvez aussi forker pour continuer sur le projet)

```bash
git clone https://github.com/ilian-458/ipinventory.git
cd ipinventory
```

### 2️⃣ Créer un environnement virtuel (venv)

```bash
python -m venv venv
```

### 3️⃣ Activer l’environnement virtuel

```bash
source venv\Scripts\activate
```
(depuis git bash ou WSL)

👉 Une fois activé, `(venv)` apparaît dans le terminal.

---

### 4️⃣ Installer les dépendances

```bash
pip install -r requierments.txt
```
